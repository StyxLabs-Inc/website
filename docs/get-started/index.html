    Get started

    Get started

    Choose between the laptop quickstart and the Kubernetes quickstart.

    There are two ways to start. Choose the one that matches your goal.

    Quickstart on a laptop#

    Time: approximately 5 minutes.

    You install one program. You do not need a Kubernetes cluster and you do not need a model API key. The program shows the model calls, the tool calls and the agent messages that your agent makes.

    Choose this path if you want to see how Sentinel works before you install the full platform. Choose it also if you want to reduce the token cost of an agent.

    Go to Quickstart on a laptop. Then read Read the numbers to learn what the program shows you.

    Quickstart on Kubernetes#

    Time: approximately 20 minutes.

    You install the full platform on a local Kubernetes cluster. The installation includes the operator, Keycloak, the web console and a sample agent.

    Choose this path if you want to deploy agents, or if you must evaluate Sentinel as a platform.

    Your container runtime must have 18 GiB of memory and 6 CPUs. A smaller machine can complete the installation, but a build from source then fails.

    Go to Quickstart on Kubernetes.

    After a quickstart#

    Do these steps in order:

    1. Configure a model. An agent cannot answer a question until you give it a model.
    2. Deploy your first agent.
    3. Connect your first tool.
    4. Install the cluster CLI, if you prefer a terminal to the web console.

    Next#
